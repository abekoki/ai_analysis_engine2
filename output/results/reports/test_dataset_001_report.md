# 個別データ分析レポート - test_dataset_001

## 概要

- 結論: 入力データに基づく検知結果は、期待される「連続閉眼あり」との一致が見られず、信頼度条件や入力特徴量の分布に問題がある可能性があります。
- 解析対象動画: test_dataset_001
- フレーム区間: 36-136
- 期待値: フレーム区間内に「連続閉眼あり」が存在すること
- 検知結果: 期待値に対して検知結果は「連続閉眼なし」となりました。

- 入出力の確認結果: 
  - 評価指標確認では、左目と右目の閉眼閾値がそれぞれ0.1で設定されているにもかかわらず、実際のデータ分布では多くのフレームでこの閾値を下回ることが確認されました。
  - 入力特徴量の分布分析では、顔検出信頼度が0.75未満のフレームが多く、これが検知結果に影響を与えた可能性があります。

- 考えられる原因:
  - 顔検出信頼度が閾値を下回るフレームが多く、信頼性の低いデータが含まれている。
  - 左右の目の開眼度が閾値を下回るフレームが少なく、連続閉眼状態の判定が困難であった。
  - 入力データの品質が期待値に対して不十分であった。

## 推奨事項

- 入力データの品質を向上させるため、顔検出信頼度が閾値を下回るフレームを除外するか、信頼度が高いフレームのみを使用することを検討してください。
- 左右の目の開眼度の閾値を見直し、より適切な値に調整することで、検知精度を向上させることが期待されます。
- 定期的にデータセットを見直し、異常値や外れ値を除去することで、アルゴリズムの信頼性を高めることが重要です。
