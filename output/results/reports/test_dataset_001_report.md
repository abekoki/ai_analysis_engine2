# 個別データ分析レポート - test_dataset_001

## 概要

- 結論: 解析対象の動画において、期待される連続閉眼状態が確認されなかった可能性が高い。これは、顔検出信頼度が閾値を下回ったため、正確な閉眼状態の判定が行えなかったことが考えられる。
- 解析対象動画: test_dataset_001
- フレーム区間: 36-136
- 期待値: フレーム区間内に「連続閉眼あり」が存在すること
- 検知結果: 連続閉眼状態は確認されず、出力は非連続閉眼状態またはエラーとなった。

- 入出力の確認結果: 
  - アルゴリズム出力では、フレーム区間内での連続閉眼状態が確認されず、出力は全体的に非連続閉眼状態またはエラーが多く見られた。
  - 顔検出信頼度が設定された閾値（0.75）を下回るフレームが多く、これが閉眼状態の判定に影響を与えた可能性がある。

- 考えられる原因:
  - 顔検出信頼度が閾値を下回ったため、正確な閉眼判定が行えなかった。
  - 入力データの品質が低下していた可能性があり、特に顔の位置や照明条件が影響したと考えられる。
  - 連続閉眼とみなす時間閾値が適切でなかった可能性がある。

## 推奨事項

- 入力データの品質を向上させるため、照明条件やカメラの位置を調整し、顔検出信頼度を向上させる。
- 顔検出信頼度の閾値を見直し、より柔軟な設定を検討することで、誤判定を減少させる。
- 連続閉眼とみなす時間閾値の調整を行い、より短い時間でも閉眼状態を検知できるようにする。
