# Project Purpose\n\nThis project is to develop an AI-based system for analyzing issues in time-series processing algorithms. It takes algorithm specifications, code, input data, output data, and expected values as inputs, performs data checks, consistency checks with specifications, hypothesis setting, verification (looping until success), and outputs a final report in a specified Markdown format. The system uses LangGraph for multi-agent architecture, RAG for retrieval, and REPL for code execution.
